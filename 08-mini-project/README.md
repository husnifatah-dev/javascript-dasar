# 08 - Mini Project: Point of Sales (POS) Sederhana

Pada modul ini, kita akan menggabungkan seluruh materi yang telah dipelajari menjadi satu program sederhana yang fungsional.

## Deskripsi Proyek
Kita akan membuat sistem kasir (Point of Sales) sederhana berbasis terminal untuk **Warung HXH**. Program ini tidak menggunakan tampilan visual (UI), melainkan murni berjalan menggunakan logika JavaScript di *console/terminal*.

## Fitur Program
1. **Katalog Menu:** Menyimpan daftar makanan dan minuman beserta harganya.
2. **Tambah Pesanan:** Menambahkan item ke dalam nota/keranjang pelanggan.
3. **Cetak Struk:** Menghitung total harga, menampilkan rincian pesanan, dan mencetak tagihan akhir.

## Materi yang Diintegrasikan
Proyek ini membuktikan bahwa kamu sudah memahami:
* **Variabel & Tipe Data**: Menyimpan harga, nama menu, dan status pesanan.
* **Array & Object**: Menyimpan *database* menu dan daftar keranjang belanja.
* **Operator & Logika**: Menghitung subtotal, total akhir, dan mengecek ketersediaan menu.
* **Perulangan (Looping)**: Menelusuri daftar menu dan mencetak isi keranjang.
* **Fungsi (Functions)**: Membungkus fitur-fitur di atas agar bisa dipanggil berulang kali.

Buka terminal dan jalankan perintah berikut:

node 01-mini-pos.js
