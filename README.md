# Belajar JavaScript Dasar

Selamat datang di repositori **JavaScript Dasar**! Repositori ini berisi catatan pembelajaran dan praktik kode untuk menguasai fondasi bahasa pemrograman JavaScript dari nol. Materi disusun secara terstruktur agar mudah dipahami, mulai dari konsep dasar hingga implementasi *mini project*.

## Daftar Modul (Silabus)
Setiap folder di bawah ini berisi file teori (README.md) dan file praktik kode (.js). 
Klik pada nama modul untuk membaca materi selengkapnya:

- 📁 01 - Pengenalan => Cara menjalankan JS (Node.js & Browser), sintaks dasar, dan console.log().
- 📁 02 - Variabel & Tipe Data => Penggunaan var, let, const, serta tipe data primitif (String, Number, dll).
- 📁 03 - Operator => Operator aritmatika, assignment, perbandingan (komparasi), dan logika.
- 📁 04 - Pengkondisian => Alur kontrol menggunakan if...else, switch...case, dan konsep Truthy/Falsy.
- 📁 05 - Perulangan (Looping) => Konsep iterasi dengan for, while, do...while, serta break & continue.
- 📁 06 - Fungsi Dasar => Deklarasi fungsi, parameter, argumen, return value, dan variable scope.
- 📁 07 - Struktur Data Dasar => Pengenalan struktur penyimpanan data menggunakan Array dan Object.
- 📁 08 - Mini Project => Pembuatan aplikasi Point of Sales (Kasir) sederhana berbasis terminal.

### Persiapan & Cara Penggunaan
Untuk menjalankan dan memodifikasi kode di repositori ini, pastikan kamu sudah menginstal:

- Code Editor: Direkomendasikan menggunakan Visual Studio Code.

- Node.js: Unduh dan instal Node.js untuk mengeksekusi file JavaScript di luar browser.

### Cara Menjalankan Kode
- Clone repositori ini ke lokal komputermu: 
```bash
git clone https://github.com/husnifatah-dev/javascript-dasar.git
```
- Buka folder repositori di Visual Studio Code.
- Buka Terminal di VS Code.
- Eksekusi file praktik menggunakan perintah node diikuti letak file-nya. Contoh: 
```bash
node 08-mini-project/01-mini-pos.js
```
